Este pez se infla como una pelota

2026-10-20 · naturaleza

Este pez se infla como una pelota ¿Qué pasaría si un pez globo se infla en mar abierto ante un depredador? Se infla tragando agua o aire y puede agrandarse a más del doble de su tamaño. Sus espinas se erizan y muchas especies tienen una toxina que las vuelve peligrosas. ¿Crees que la pelota de este pez sirve más para defensa o escapar? Mañana: la hormiga cortadora.

Lo que dicen las fuentes

  • Los peces globo pueden inflarse tragando agua o aire como forma de defensa.
  • Muchas especies de peces globo tienen tetrodotoxina, una toxina que puede ser peligrosa.
